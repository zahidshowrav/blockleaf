title: Text styles

---

Text styles ship as an opt-in subpath, not in the default bundle.

```ts
import { presets } from '@blockleaf/editor/extensions';
import { withTextStyle } from '@blockleaf/editor/text-style';

const extensions = withTextStyle(presets.standard());
```

```tsx
<BlockleafEditor extensions={extensions} />
```

They are new in schema version 2.

## Subscript and superscript

| Style       | Shortcut  | Stored as                   | Written as |
| ----------- | --------- | --------------------------- | ---------- |
| Subscript   | `Mod`+`,` | `{ "type": "subscript" }`   | `<sub>`    |
| Superscript | `Mod`+`.` | `{ "type": "superscript" }` | `<sup>`    |

- **One or the other, never both.** Text cannot sit above and below the line
  at once, so turning one on turns the other off. A stored run never carries
  both.
- **The bubble menu gains two buttons**, Subscript and Superscript, after
  Highlight. An editor without the subpath has no such marks, so the buttons
  are not offered there; see
  [actions follow the extension set](./chrome.mdx#actions-follow-the-extension-set).
- **Pasted `<sub>` and `<sup>` arrive as the marks**, from a web page or a
  word processor.
- **`@blockleaf/renderer` writes `<sub>` and `<sup>`** on both targets, with
  no extra import.

## Text alignment

| Alignment | Shortcut          | Stored as                             |
| --------- | ----------------- | ------------------------------------- |
| Left      | `Mod`+`Shift`+`L` | `"attrs": { "textAlign": "left" }`    |
| Center    | `Mod`+`Shift`+`E` | `"attrs": { "textAlign": "center" }`  |
| Right     | `Mod`+`Shift`+`R` | `"attrs": { "textAlign": "right" }`   |
| Justify   | `Mod`+`Shift`+`J` | `"attrs": { "textAlign": "justify" }` |

- **Paragraphs and headings.** Every one in the selection, so a whole
  section aligns at once. Other blocks are left alone.
- **The same choice again takes it off**, and the block goes back to the
  language's own direction — left in English, right in Arabic. An unaligned
  block stores nothing at all.
- **The block menu gains an Align group** — Left, Center, Right, Justify —
  for a paragraph or heading.
- **Only those four values are stored.** Pasted `text-align: center` arrives
  aligned; anything else, such as `start`, arrives unaligned. A stored value
  outside the four fails validation, and the renderer ignores it rather than
  writing it into a `style` attribute.
- **`@blockleaf/renderer` writes `style="text-align: …"`**, as the editor
  does.

### Why the attribute is not in the subpath

The commands, shortcuts and menu entries come with
`@blockleaf/editor/text-style`. The `textAlign` attribute itself is in every
preset. An editor keeps a mark it does not know, but it drops an attribute
it does not know — so if the attribute lived here, opening an aligned
document in an editor without the subpath and saving it would remove the
alignment, silently. With the attribute in the core, every editor shows and
keeps it; only setting it needs the subpath. The reasoning is F25 in
[`open-flags.md`](https://github.com/zahidshowrav/blockleaf/blob/main/docs/open-flags.md).

## Without the subpath

An editor that does not load `@blockleaf/editor/text-style` still opens a
document that uses these styles. Subscript and superscript text shows
plainly, and the marks are saved back exactly as they came in. Alignment
shows and is kept, as above; it just cannot be changed. See
[a block the editor does not know](./getting-started.mdx#a-block-the-editor-does-not-know).

## `withTextStyle` versus `createTextStyle`

`withTextStyle` removes any extension with the same name before adding its
own, so adding it twice, or over Tiptap's own subscript, never leaves two
extensions fighting over one name. `createTextStyle()` returns the same
extensions as a plain array, for a list you are assembling from scratch.

## Cost

Measured with `size-limit`, minified and brotlied: the editor is
**151.35 kB** — the alignment attribute and the block menu's Align entries
included — and the editor with text styles is **151.80 kB**, so **0.45 kB**
for the marks, the alignment commands and their shortcuts. Without the
import, only the attribute and the menu entries are in the bundle, and the
menu entries do not appear.
