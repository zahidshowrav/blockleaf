# @blockleaf/math

## 0.1.0

### Minor Changes

- 8479f86: New package: LaTeX formulas, inside a line (`mathInline`) or as their own block (`mathBlock`), drawn by KaTeX as MathML by default. `withMath` adds them to the editor; `createMathComponents` from `@blockleaf/math/react` and `@blockleaf/math/html` draws them in the renderer. New in schema version 2; `katex` is a peer dependency.
